# Privacy
Feather Launcher has no advertising, analytics, telemetry, background service or auto-start behavior. Phase 1 makes no account or Minecraft network requests. Settings, logs, cache and instances remain in the displayed local application-data directory. Logs automatically redact common token, password, email and account-ID forms, but users should still inspect diagnostic material before sharing it. Future authentication will use Microsoft-controlled browser flows and secure OS credential storage; the launcher will never collect Microsoft passwords. Users can delete local data by removing the displayed application-data folder after closing the launcher.

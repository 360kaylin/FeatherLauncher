# Feather Launcher

An early, unofficial, free and lightweight launcher for **Minecraft: Java Edition**. Phase 1 supplies only the application foundation—Minecraft authentication and launching are deliberately not implemented.

> Not an official Minecraft product. Not approved by or associated with Mojang or Microsoft.

## Current features
- Avalonia desktop shell with honest feature placeholders
- Local settings for theme, game-start behavior, update checks, cache limit and instance location
- Live local diagnostics, safe application paths and credential-redacting logs
- Layered .NET solution, tests and Windows portable CI packaging

See [BUILDING.md](BUILDING.md), [USER_GUIDE.md](USER_GUIDE.md), and [PLAN.md](PLAN.md). The project does not support cracked/offline account bypasses and never asks for a Microsoft password.
